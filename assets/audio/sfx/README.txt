Skillverse / Gamified Learning App - Original SFX Pack
======================================================
These 19 sound effects were procedurally synthesized for this project.
They do not contain third-party sampled audio.

Put the MP3 files directly in:
  assets/audio/sfx/

Filenames are already matched to the Flutter implementation:
  ui_tap.mp3
  answer_select.mp3
  answer_correct.mp3
  answer_wrong.mp3
  next_question.mp3
  countdown_tick.mp3
  coin_reward.mp3
  xp_reward.mp3
  streak_up.mp3
  streak_milestone.mp3
  power_up.mp3
  add_time.mp3
  skip.mp3
  timeout.mp3
  quiz_complete.mp3
  perfect_score.mp3
  level_up.mp3
  match_connect.mp3
  card_drop.mp3

Suggested workflow:
  1. Copy all MP3 files into assets/audio/sfx/
  2. Keep or remove .gitkeep; it does not matter once files exist.
  3. Run: flutter clean
  4. Run: flutter pub get
  5. Run: flutter run
  6. Test on a physical Android device and adjust central volumes if desired.
